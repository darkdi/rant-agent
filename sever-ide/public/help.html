Installation (English)

Rant Agent is a single-user local application. Its UI is currently Russian. Start with one model route; neither Ollama nor MLX is mandatory.

Prerequisites

  • macOS or Linux; Python 3.12+ with venv, Node.js 22.13+ with npm, Git.
  • A browser for the UI; Chrome 120+ only if you want the browser agent.
  • Internet for first-time package/model downloads. No automatic weight downloads.
  • API mode does not require a GPU. Local model memory requirements depend on weights and context. Native Windows and WSL are not validated in this alpha.

Install prerequisites from Python, Node.js, and Git. Linux users may need the distribution's python3-venv package.

git clone https://github.com/darkdi/rant-agent.git
cd rant-agent
./start.sh

Open http://127.0.0.1:4311. Keep the terminal running. Ctrl+C stops the app. The launcher caches dependency/build fingerprints and rebuilds when source changes.

Other options:

./start.sh --check
./start.sh --no-open --no-browser
./start.sh --port 4321 --preview-port 4322
./start.sh --rebuild

Model routes

Click the model name, then Добавить модель (Add model).

  • Ollama: install and open Ollama, run ollama pull qwen3:4b. Choose the Ollama preset (http://127.0.0.1:11434/v1), fetch the model list, select the downloaded model, save. Normal local Ollama does not need a key. Official compatibility reference.
  • LM Studio: download/load a model, start its Developer server. Choose LM Studio (http://127.0.0.1:1234/v1), fetch models and save. Add a key only if server authentication is enabled. Official server setup.
  • API: select a provider or Другой сервис, provide the base URL, your key and exact model ID. Use the API format the provider supports. Save-and-test performs a real, potentially billable request. Save alone only stores configuration.

For built-in Qwen3.5-9B-4bit on Apple Silicon, after the first base installation:

.venv/bin/pip install -r requirements-mlx.txt
.venv/bin/python scripts/setup_model.py --download
./start.sh

The explicit download uses ~/Models/Qwen3.5-9B-4bit. To reuse existing MLX weights instead:

.venv/bin/python scripts/setup_model.py --path "$HOME/Models/Qwen3.5-9B-4bit"

Use --replace to change an existing registration. The built-in runtime does not accept GGUF. The first chat loads the weights; following requests reuse them. Выгрузить Qwen из памяти unloads the model. Weight/model licenses are separate from Rant's MIT license.

Browser extension

Start Rant first. In Chrome, open chrome://extensions, enable Developer mode and load unpacked sever-ide/chrome-extension from this checkout. Open Rant Agent Local — браузер, approve the requested Chrome permissions, then enable the browser inside Rant's Настройки и возможности → Доступы and save. Switch the composer to browser mode.

Pairing tokens and ports are generated per installation. After updating, reload that extension in Chrome. Do not overwrite or disable extensions belonging to another installation. Passwords and one-time codes should be entered manually in Chrome.

Media

Создать картинку / Создать видео on the welcome screen (or sidebar) opens the media studio. Configure an independent media provider. Media guide covers Images API, Replicate and local ComfyUI. Chat models are not media-generation engines.

Data, updates and troubleshooting

Settings, chats, media and keys live under sever-ide/.local. Projects normally live under sever-ide/projects; external project folders remain where you selected them. Stop the app and back these up privately before updates. Keys have filesystem permissions but are not encrypted. Never publish these directories.

git pull --ff-only
./start.sh

If a port is occupied, use the alternative-port command above. If a model fails, check it in Ollama/LM Studio directly or inspect Qwen's setup error. API errors usually require checking endpoint, model identifier, format or provider credentials. For full troubleshooting and screenshots of UI labels, use the Russian guide. See security before enabling external tools.

Browser, desktop and MCP connectors

Chrome, Rant Connect Local and MCP — setup guide. Personal connector archives are available in Инструменты и приложения. Desktop control requires a vision/tool-capable model and explicit activation in the visible companion window.

Image and video generation

Open Create an image or Create a video on the welcome screen, or Images / Video in the sidebar. Add a connection separately for each media type. Saving a connection makes no generation request. Your provider charges for API generation; Rant adds no credits or billing layer. Local workflows use your hardware, but custom workflow nodes may call paid APIs.

Images API

Choose Images API · OpenAI-compatible, enter a connection name, the provider's base URL (usually ending in /v1), API key, and exact image model ID. This adapter sends POST /images/generations with model, prompt, and n: 1. It accepts a base64 image or result URL. It does not turn a chat-only model into an image model.

Under Model parameters, paste a JSON object of parameters supported by that model, such as size or quality. Do not put credentials in this object. The prompt comes from your description; model and count are controlled by the app. Arbitrary multipart image-editing APIs are not supported.

Replicate images or video

Select Replicate, use https://api.replicate.com/v1, and enter your own token. Set the model to owner/model for an official model, or owner/model:version with its full version hash. Set duration, aspect ratio and other supported inputs in Model parameters. Consult the selected model's input schema: there is no universal parameter set for every model.

The adapter creates one prediction and polls its status. It expects an image/video URL or a list of URLs and keeps the first result. Video must be MP4 or WebM. The job ID is shown for checking its status in Replicate. See the Replicate HTTP API.

Local ComfyUI

Install ComfyUI separately, add the model weights and nodes your workflow needs, and first confirm that the workflow runs successfully in ComfyUI itself. Rant does not install model weights or build workflows automatically. Qwen/Ollama chat models do not generate images/video through this adapter.

  1. Start ComfyUI locally, normally at http://127.0.0.1:8188.
  2. Export a working workflow in API format, not the ordinary visual-editor format.
  3. Replace its positive prompt text with __PROMPT__. Keep the negative prompt unchanged.
  4. In Rant choose ComfyUI, enter the local address and paste the workflow JSON. An API key is optional.
  5. Save the connection, enter your description, and generate.

An image workflow must save PNG/JPEG/WebP. A video workflow must save MP4/WebM in an output reported under images, gifs, or videos. Install any custom nodes required by your workflow. Rant uses /prompt, /history/{id}, and /view; see ComfyUI routes. Only loopback ComfyUI endpoints are supported.

Results, limits and recovery

Results are stored under sever-ide/.local/media and can be downloaded from the gallery. They persist after closing the dialog. Keep Rant running while generation is active. The current limits are one active job, 60 gallery entries, approximately 1 GB of saved results, a 100 MB downloaded result, and a 32-megapixel image. Images are normalized to PNG. Back up the files you need before clearing the media folder while Rant is stopped.

Generation requests are never automatically resubmitted. If the app restarts or loses a response, the job is marked for review: it may have completed at the provider. Check the provider dashboard or ComfyUI history before generating again. Repeating a paid request may incur another charge. A provider's progress bar or quality cannot be inferred from a connection being saved.

API keys are stored separately from connection metadata in a private local directory; they are not encrypted. Output downloads do not receive provider credentials. Use only trusted providers and workflows.

Adapter contract tests cover synthetic responses. A real paid generation or your particular ComfyUI model still needs verification after setup.

Browser, desktop and MCP connectors

These instructions are for the open-source local app on macOS/Linux. A Rant account or subscription is not required. Your chosen API provider may charge for model usage. The local connectors are separate from the cloud version for ai.rant.ae.

Chrome

  1. Start Rant and open Tools and apps → Your Chrome.
  2. Click Download extension for this installation. This ZIP contains a personal pairing key and this installation's ports. Do not publish or share it.
  3. Extract to a permanent folder. Open chrome://extensions, enable Developer mode, click Load unpacked, and select the folder containing manifest.json.
  4. Open Rant Agent Local from Chrome's extension menu and grant browser access. In Rant settings, open Permissions and enable the browser agent.
  5. The connector should show Connected. Try Use the browser with a small task on a public HTTPS page.

The extension reads pages, navigates, clicks and fills forms for your tasks. Page content may be sent to your model provider. Enter passwords and verification codes yourself. The cloud extension does not pair with the local app automatically.

If disconnected, keep Rant running, click Check connection, and reload the extension in Chrome. After reinstalling Rant, download the archive again. The bridge selects a free port pair without stopping unrelated processes. Downloading the extension starts the bridge even after launching with --no-browser.

Rant Connect Local

This experimental companion controls the same computer running Rant. It does not connect to ai.rant.ae, open an inbound port, or install a background service. Connecting another computer over a network is outside this local package's scope.

Install

Use Python 3.12+ with Tk. Check with python3 -c "import tkinter". On Mac, install a Python distribution including Tcl/Tk from python.org or the Tk package matching your Python version.

In Tools and apps → Rant Connect Local, download and extract the archive. Run Start.command on Mac. If needed:

chmod +x Start.command
./Start.command

Choose another Python with PYTHON_BIN=/full/path/to/python3 ./Start.command. First launch creates a separate .venv and installs dependencies. It downloads no models.

On Debian/Ubuntu with a graphical X11 session:

sudo apt-get install python3-venv python3-tk python3-dev scrot xclip
sh Start.command

Wayland and a native Windows Rant host are not supported in this alpha.

Pair and use

  1. Check that the companion shows the same local address as Rant, for example http://127.0.0.1:4321.
  2. In Rant click Create pairing code, then enter it in the companion. The code expires in five minutes and can be used once.
  3. On Mac grant Screen Recording and Accessibility permissions to the Python/Terminal running the companion, then restart it if required.
  4. Explicitly enable control in the companion window. It starts with control off every time.
  5. Choose an API or local API-server model supporting both images and tool calls. The built-in text-only MLX path does not support desktop tools yet.
  6. Start with a simple request, such as asking which window is visible, then try a small task in a test document.

Connect can capture the main monitor, click, type, send shortcuts and scroll. Screenshots go to your chosen model, including its external provider when using a remote API. Model-specific vision accuracy needs local testing. This is not a shell or SSH interface.

Stop and revoke

Stop in the companion or close its window to disable execution. Stop in chat ends the task and cancels pending commands; it cannot undo an action already performed. Move the mouse to the main monitor's top-left corner for PyAutoGUI's fail-safe at the next control call. Remove a computer in Rant to revoke its token; pairing again requires a new code.

On connection errors, control turns off. Received commands are not automatically redelivered. If a response is lost, an action may have happened: inspect the screen before repeating it. Only one paired computer may be armed at once.

Tokens live under ~/.rant-connect-local/, separately for each local address. The downloaded companion ZIP has an address but no pairing token. If you change ports, download it again or set RANT_LOCAL_URL=http://127.0.0.1:NEW_PORT and pair again.

MCP

Enter a name, public HTTPS MCP Streamable HTTP endpoint and optional token in Tools and apps. Click Check and list actions, then allow only the actions you need. Connection discovery does not automatically grant tool access.

Text results and Bearer tokens are supported; OAuth and local stdio transport are not. MCP works with API-connected models, including compatible local servers, that support tool calls. You can revoke permissions or remove the connection at any time.

Verification

Automated tests cover one-use/expired codes, revocation, cancellation, no command redelivery, coordinate conversion and HTTP relay/downloads with a synthetic client. They do not operate the real desktop. Test your selected model and OS permissions locally. This release provides source launchers, not signed native installers.

Rant Agent — установка с нуля

Это локальное приложение для одного пользователя. Регистрация в Rant и подписка не нужны. За сторонние API ты платишь своему провайдеру; локальные модели используют ресурсы компьютера.

1. Подготовь компьютер

  • macOS или Linux. Нативная Windows в этой альфе не поддерживается. WSL пока не проверен.
  • Python 3.12 или новее, с модулем venv.
  • Node.js 22.13 или новее, включая npm.
  • Git для скачивания и обновлений.
  • Обычный браузер для интерфейса. Для браузерного агента нужен Chrome 120+.

Для API-режима не нужно скачивать модель. Объём памяти для локальной генерации зависит от модели, контекста и других приложений. Для Qwen 9B разумно начинать с Mac с 16 ГБ памяти, лучше иметь запас; это ориентир, не гарантия работы любого контекста. При нехватке памяти используй меньшую модель в Ollama. Видео требует существенно больше ресурсов, чем чат.

macOS

Установи Python с python.org и Node.js с nodejs.org. Git доступен через инструменты разработчика Apple или git-scm.com.

Если Homebrew уже установлен, можно выполнить:

brew install python@3.12 node git

Проверь версии в новом окне Терминала:

python3 --version
node --version
npm --version
git --version

Если python3 всё ещё старый, используй нужный интерпретатор явно: PYTHON_BIN=python3.12 ./start.sh.

Linux

Установи Git, Python 3.12+ и пакет venv через менеджер пакетов своего дистрибутива. Например, Ubuntu 24.04:

sudo apt update
sudo apt install git python3 python3-venv python3-pip

Node.js установи по официальной инструкции, затем проверь node --version. Не все дистрибутивы поставляют нужную версию Node/Python по умолчанию. Реальный локальный запуск этого выпуска проверен на macOS Apple Silicon; Linux проверяется дополнительно в CI и не означает проверку каждого дистрибутива/драйвера GPU.

2. Скачай приложение

git clone https://github.com/darkdi/rant-agent.git
cd rant-agent
./start.sh

Первый запуск создаёт изолированное окружение .venv, устанавливает зависимости и собирает интерфейс. Нужен интернет; веса моделей не скачиваются. После сборки откроется http://127.0.0.1:4311.

Оставь Терминал открытым. Для остановки нажми Ctrl+C. При следующем запуске выполни ./start.sh из той же папки. На Mac можно открыть Start-Rant.command.

Если скачал ZIP через GitHub, распакуй его, открой Терминал в полученной папке и выполни:

chmod +x start.sh Start-Rant.command
./start.sh

./start.sh --check только проверяет предпосылки и порты, ничего не устанавливает. --no-open отключает автоматическое открытие браузера. --no-browser запускает без моста расширения.

3. Выбери один способ подключения модели

Ollama не обязательна. Достаточно одного варианта: Ollama, LM Studio, встроенная Qwen или API. Подключения чата и генерации картинок/видео отдельные.

Вариант A. Ollama — локальные модели

  1. Скачай и установи Ollama, запусти приложение.
  2. Скачай модель в Терминале:
ollama pull qwen3:4b
ollama list
  1. Проверь ответ без Rant:
ollama run qwen3:4b

Напиши короткий вопрос. Для выхода из чата введи /bye. 4. Если служба не запущена, выполни ollama serve в отдельном окне. Если пишет, что порт занят, Ollama, вероятно, уже работает; вторую службу запускать не нужно. 5. В Rant нажми название модели сверху → Добавить модель → Ollama. 6. Адрес: http://127.0.0.1:11434/v1. Обычная локальная Ollama не требует API-ключ. 7. Нажми Получить список с сервера, выбери точное название установленной модели. 8. Нажми Сохранить и проверить, затем Готово, отправь сообщение.

Пресет использует формат Chat Completions. Он совместим с Ollama OpenAI API. Rant не устанавливает Ollama и её модели вместо тебя.

Для агентных задач модель должна поддерживать вызов инструментов. Успешный короткий ответ не доказывает, что она справится с браузером или редактированием файлов. Для простого чата сначала оставь автоматическое сжатие выключенным — так меньше дополнительных запросов.

Размер контекста на стороне Ollama настраивается отдельно. Поле контекста в Rant не меняет настройки движка. Например, файл Modelfile:

FROM qwen3:4b
PARAMETER num_ctx 8192

ollama create rant-qwen -f Modelfile

Затем выбери rant-qwen в Rant. Больший контекст расходует больше памяти. Официальная документация.

Вариант B. LM Studio

  1. Установи LM Studio, скачай подходящую модель внутри приложения.
  2. Загрузи модель. Открой Developer и запусти локальный сервер (Start Server).
  3. В Rant: название модели → Добавить модель → LM Studio.
  4. Оставь http://127.0.0.1:1234/v1, если в LM Studio не указан другой порт.
  5. Получи список моделей, выбери нужную и сохрани. Ключ не нужен, если ты отдельно не включил авторизацию сервера.

Инструкция локального сервера LM Studio.

Вариант C. Встроенная Qwen 3.5 9B через MLX

Только Mac с Apple Silicon. Ollama и LM Studio для этого варианта не нужны.

Из корня Rant, после первого запуска:

.venv/bin/pip install -r requirements-mlx.txt

Если весов ещё нет, явно запусти скачивание нескольких гигабайт:

.venv/bin/python scripts/setup_model.py --download

По умолчанию файлы окажутся в ~/Models/Qwen3.5-9B-4bit. Используется mlx-community/Qwen3.5-9B-4bit. Проверь карточку и лицензию модели перед использованием.

Если правильные MLX-веса уже скачаны, повторно скачивать их не нужно:

.venv/bin/python scripts/setup_model.py --path "$HOME/Models/Qwen3.5-9B-4bit"

Чтобы заменить существующую настройку, добавь --replace. Это меняет только путь модели, не удаляет старые веса.

Альтернатива — вручную создать local-assistant/model-9b.json:

{"path": "/полный/путь/к/Qwen3.5-9B-4bit"}

Нужна папка модели с config.json, файлами токенизатора и всеми .safetensors. GGUF из Ollama/LM Studio не подходит этому MLX-загрузчику.

Перезапусти Rant, выбери Qwen3.5-9B · MLX 4-bit и напиши сообщение. Первый запрос загружает модель; затем статус станет Qwen в памяти. В настройках есть Выгрузить Qwen из памяти. Встроенный режим в этом выпуске работает с текстом; картинки передавай модели с поддержкой зрения через подходящий API.

MLX-LM — отдельный движок с собственной документацией. Rant не обучает модель и не включает веса в репозиторий.

Вариант D. API со своим ключом

  1. Получи ключ у выбранного провайдера. Подписка на чат-сайт и доступ к API могут оплачиваться отдельно.
  2. В Rant открой Добавить модель и выбери провайдера или Другой сервис.
  3. Укажи базовый адрес API, например адрес до /v1, а не полный путь /chat/completions.
  4. Вставь ключ, получи список моделей или введи точный ID из кабинета провайдера.
  5. Проверь формат в дополнительных настройках: Chat Completions, Responses или Anthropic Messages. Не все провайдеры поддерживают все три.
  6. Сохранить и проверить отправляет реальный короткий запрос — он может тарифицироваться. Сохранить только записывает подключение.

Ключ хранится локально, переживает перезапуск и не отображается обратно в поле. Удалить сохранённый ключ можно в настройках подключения. Изменение адреса на другой сервер не переносит прежний ключ автоматически.

4. Подключи Chrome

Расширение не требуется для обычного чата. Safari может показывать интерфейс Rant, но агент управляет Chrome.

  1. Запусти Rant. При старте он создаст персональный sever-ide/chrome-extension/config.js.
  2. В Chrome открой chrome://extensions и включи режим разработчика.
  3. Нажми Загрузить распакованное расширение и выбери sever-ide/chrome-extension именно этой копии Rant.
  4. Закрепи расширение Rant Agent Local — браузер, открой его и нажми Разрешить Chrome. Chrome покажет запрашиваемые разрешения.
  5. В Rant открой Настройки и возможности → Доступы, включи браузер и сохрани разрешения. Под полем сообщения выбери режим браузера.
  6. Начни с чтения обычной публичной HTTPS-страницы. Вход на сайты, пароли и коды вводи сам в Chrome.

Мост выбирает свободные порты и сохраняет их в .local/browser-ports.json. Разные копии Rant имеют разные токены и настройки. Не заменяй расширение, используемое другим приложением: для этой копии загружай её собственную папку. После обновления кода нажми ↻ на её карточке в chrome://extensions.

Не публикуй config.js, токен расширения или всю .local. Ошибка «мост запущен, Chrome не подключён» обычно означает, что расширение ещё не загружено, не обновлено или относится к другой папке.

5. Проекты и файлы

Нажми + рядом с проектами и создай пространство. Новые папки создаются в sever-ide/projects; личные чаты могут иметь внутренние папки в .local/workspaces. Включи Файлы и код, чтобы открыть редактор, историю изменений и предпросмотр.

Приложение умеет ограниченные правки текстовых файлов. Это не терминал: оно не запускает произвольные команды, тесты твоего проекта или деплой. Предпросмотр предназначен для статических HTML/CSS/JS. Ограничения текущего файлового инструмента: до 24 КБ на файл и 100 индексируемых файлов.

6. Изображения и видео

На стартовом экране нажми Создать картинку или Создать видео. Эти кнопки доступны также в боковом меню. Сначала добавь отдельное медиа-подключение. Полная инструкция студии.

7. Обновления и резервная копия

Останови Rant через Ctrl+C. Сохрани копию sever-ide/.local, sever-ide/projects, local-assistant/model-9b.json и своих внешних проектов в личное защищённое место. Архив содержит ключи и личные данные — не прикладывай его к GitHub issues.

git pull --ff-only
./start.sh

Если менял исходники, сначала сохрани свои изменения. --ff-only не перепишет их и остановится при конфликте. Лаунчер заметит изменения зависимостей и интерфейса; для принудительной пересборки используй ./start.sh --rebuild.

Изображения и видео / Media generation

Студия открывается кнопками Создать картинку и Создать видео на стартовом экране либо Картинки / Видео в меню. Она работает отдельно от чат-модели. Qwen, Ollama и обычный Chat Completions API сами по себе не превращаются в генератор изображений или видео.

Как устроена студия

  1. Выбери нужный тип результата.
  2. Добавь подключение: название, адаптер, адрес, модель, свой ключ при необходимости.
  3. Сохрани подключение. Это не запускает генерацию и не проверяет платный API.
  4. Опиши результат и нажми Создать. Запрос уходит выбранному движку.
  5. Окно можно закрыть. Пока приложение Rant запущено, задача продолжится в фоне. Результат появится в галерее; его можно посмотреть и скачать.

Сейчас одна генерация выполняется за раз. Сохраняется первый подходящий выход модели: PNG для картинки, MP4/WebM для видео. Максимум 100 МБ на результат, 32 мегапикселя для изображения, 60 работ и примерно 1 ГБ галереи. Файлы лежат в sever-ide/.local/media. Видеоформат зависит от выбранной модели/workflow; монтаж и звук не добавляются автоматически.

Images API — картинки по API

Выбери Images API · OpenAI-совместимый. Укажи базовый URL до /v1 или аналогичного API-префикса, ключ и точное имя модели из документации провайдера. Rant отправляет JSON в /images/generations: model, prompt, n: 1, плюс твои дополнительные параметры.

Ответ должен содержать data[0].b64_json либо data[0].url. Картинка проверяется и сохраняется локально. Поддерживается также loopback-сервер с этим API. Для собственного формата нужен новый адаптер, а не просто изменение адреса.

В Параметрах модели можно задать, например:

{"size": "1024x1024"}

Добавляй quality, response_format и другие поля только если конкретный сервис их поддерживает. Единого универсального списка моделей нет. Не вставляй ключи в JSON параметров — для них есть отдельное поле.

Replicate — картинки и видео по API

Нужен свой аккаунт, платёжные настройки и API-токен Replicate. В зависимости от выбранной модели результатом будет изображение или видео.

  • Адаптер: Replicate.
  • Адрес: https://api.replicate.com/v1.
  • Модель: owner/model для официального endpoint модели либо owner/model:version для версии prediction API.
  • Ключ: свой API-токен.
  • JSON параметров: поля input из документации выбранной модели, кроме prompt, который берётся из описания Rant.

Пример формы параметров, только если модель поддерживает эти поля:

{"aspect_ratio": "16:9", "duration": 5}

Rant отправляет prediction один раз, сохраняет его ID и опрашивает статус до 20 минут. Успешный выход должен быть URL файла либо списком URL; первый файл скачивается без передачи токена на сервер хранения. Схема модели и доступность её версии — ответственность конкретного endpoint. Официальный API Replicate.

ComfyUI — локальные изображения и видео

Нужен отдельно установленный ComfyUI и рабочая схема с нужными весами. Rant не устанавливает CUDA, видеомодели или custom nodes автоматически. Требования зависят от модели и GPU; наличие текстовой Qwen не означает, что памяти хватит для видео.

  1. Запусти ComfyUI на loopback, обычно http://127.0.0.1:8188.
  2. Сначала получи правильный результат в самом ComfyUI.
  3. Экспортируй эту схему в API-формате. Включение соответствующего режима зависит от версии интерфейса ComfyUI.
  4. В JSON замени положительный текстовый промпт на __PROMPT__. Отрицательный промпт и остальные параметры оставь из проверенной схемы.
  5. В Rant выбери ComfyUI, укажи адрес и вставь JSON.
  6. Для картинки нужен сохранённый PNG/JPEG/WebP, для видео — MP4/WebM. Rant читает результаты узлов images, gifs или videos через историю задачи и /view.

Поддерживаются только локальные адреса ComfyUI. Схема — исполняемый граф на твоём сервере: подключай доверенные узлы. Некоторые custom/partner nodes обращаются во внешние платные API; это не полностью офлайн-генерация. Документация маршрутов ComfyUI.

Ошибки и оплата

Rant не продаёт кредиты и не знает итоговую цену твоего сервиса. Нажатие Создать может запустить платную генерацию у выбранного API-провайдера.

Если связь оборвалась, запрос не отправляется повторно автоматически. Статус «Нужно проверить результат» не означает, что провайдер ничего не создал или не списал деньги. Проверь сохранённый ID в сервисе перед повтором. Перезапуск Rant помечает незавершённые задачи как требующие проверки; автоматического повторного запуска нет.

Если ComfyUI не вернул файл, проверь, что схема завершилась и содержит узел сохранения нужного формата. Если API вернул HTTP-ошибку, сверь адрес, модель, ключ и параметры.

Что проверено в первом выпуске

Проверяются контрактные тесты адаптеров, сохранение результатов, исключение ключей из публичного состояния, отсутствие повторной отправки и обработка ошибок. Реальная генерация через платные медиа-API и через установленный ComfyUI не включается в автоматические тесты: она требует твоего ключа, модели/весов и может стоить денег. Не считай поддержку адаптера гарантией совместимости любой модели.

English summary

Use a separate media connection. Images API accepts POST /images/generations; Replicate accepts model predictions or versioned predictions; local ComfyUI accepts an API workflow containing __PROMPT__. The app submits once, polls asynchronous work, and stores the first supported image/video locally. Keys are never forwarded to output storage URLs. No paid media generation or real ComfyUI execution is part of the offline test suite.

Браузер, компьютер и внешние сервисы

Rant Agent Local работает на macOS/Linux. Всё ниже относится к локальной открытой версии, а не к облачному Rant Connect для ai.rant.ae. Аккаунт Rant и подписка не нужны. API выбранной модели оплачивается у её провайдера.

Chrome

  1. Запусти Rant обычным ./start.sh и открой Инструменты и приложения → Твой Chrome.
  2. Нажми Скачать расширение для этой установки. Архив создаётся с её портами и персональным ключом подключения; не выкладывай этот архив в GitHub и не передавай другим.
  3. Распакуй ZIP в постоянную папку. В Chrome открой chrome://extensions, включи Режим разработчика, нажми Загрузить распакованное и выбери папку с manifest.json.
  4. Открой значок Rant Agent Local — браузер и разреши Chrome. В Rant открой Настройки и возможности → Доступы и включи Браузерный агент.
  5. В разделе подключений должен появиться статус Подключён. Выбери на главной Поручить браузеру и дай небольшое поручение, например найти публичную страницу документации.

Расширение читает страницы, открывает вкладки, нажимает и заполняет поля по поручению. Содержимое страниц может попасть к выбранному поставщику модели. Открытое расширение облачной версии не подключает локальную автоматически: это разные установки.

Если подключение пропало, проверь, что Rant запущен, нажми Проверить подключение, обнови расширение в Chrome. После переустановки приложения скачай архив заново. Мост выбирает свободную пару портов и не останавливает чужие процессы. Скачивание расширения запускает мост, даже если приложение ранее запускалось с --no-browser.

Rant Connect Local — экран и приложения

Это экспериментальный режим для того же компьютера, где запущен Rant. Он не подключается к ai.rant.ae, не открывает входящий порт и не устанавливает фоновую службу. Для другого компьютера по сети этот локальный пакет не предназначен.

Установка на Mac

  1. Нужен Python 3.12+ с Tk. Проверка импорта: python3 -c "import tkinter". Если модуля нет, установи Python с Tcl/Tk из python.org или Tk для своей версии Python. Не смешивай несовместимые версии Python и Tk.
  2. В Rant открой Инструменты и приложения → Rant Connect Local → Скачать.
  3. Распакуй архив. Открой Start.command. Если нет права исполнения, в терминале перейди в распакованную папку и выполни:
chmod +x Start.command
./Start.command

Первый запуск создаёт отдельную .venv и устанавливает зависимости, не скачивая модели. Если нужно выбрать Python, используй PYTHON_BIN=/полный/путь/к/python3 ./Start.command.

  1. В открытом окне проверь адрес: он должен совпадать с локальным Rant, например http://127.0.0.1:4321.
  2. В Rant нажми Создать код подключения. Вставь код в Connect. Код действует пять минут и используется один раз.
  3. В настройках macOS разреши использованному Python/Терминалу Запись экрана и Универсальный доступ, если система запросит их. После изменения разрешений может понадобиться перезапуск Connect.
  4. Нажми Включить управление в окне Connect. В Rant статус изменится на Управление включено.

Linux

Нужна графическая сессия X11. Wayland в этой альфе не поддерживается. Для Debian/Ubuntu установи системные зависимости:

sudo apt-get install python3-venv python3-tk python3-dev scrot xclip

Распакуй архив, затем запусти sh Start.command. Дальше используй одноразовый код и кнопку включения, как на Mac. Системные зависимости и ограничения основного монитора описаны в документации PyAutoGUI.

Модель и первое поручение

В настройках модели выбери API или локальный OpenAI-совместимый сервер с моделью, поддерживающей изображения и вызовы инструментов. Сервер сам по себе не гарантирует эти возможности модели. Встроенный текстовый путь Qwen через MLX пока не получает инструменты экрана. Для него остаются чат, файлы и браузерный режим.

Когда Connect включён, в обычном чате можно попросить: «Посмотри на мой экран и скажи, какое окно открыто». Затем попробуй небольшое поручение в тестовом документе. Connect умеет делать снимки основного монитора, нажимать, вводить текст, отправлять сочетания клавиш и прокручивать. CLI/SSH-инструменты в этот режим не добавлены.

Снимки передаются выбранной модели; при внешнем API они уходят его провайдеру. Приложение не проверяет автоматически качество распознавания конкретной моделью.

Остановка и отзыв

  • Остановить управление в Connect или закрыть его окно — отключить исполнение.
  • Стоп в чате — остановить текущую задачу и отменить ожидающие команды. Уже выполненное действие автоматически не откатывается.
  • Мышь в верхний левый угол основного монитора — экстренная остановка при следующем вызове управления.
  • Кнопка удаления возле компьютера в Rant — отозвать его токен. Для повторного подключения нужен новый код.

После запуска Connect управление всегда выключено. При потере связи оно выключается; полученная команда не отправляется повторно автоматически. Если ответ потерян, действие могло выполниться: сначала проверь экран. При нескольких включённых компьютерах действие отклоняется, пока не останется один.

Токен хранится в ~/.rant-connect-local/ отдельно для каждого локального адреса; исходный код и архив скачивания Connect токен не содержат. При смене порта скачай Connect заново или задай RANT_LOCAL_URL=http://127.0.0.1:НОВЫЙ_ПОРТ перед запуском и выполни новое подключение.

MCP

В Инструментах и приложениях введи название, публичный HTTPS-адрес MCP Streamable HTTP и токен при необходимости. Нажми Проверить и показать действия, затем отметь нужные инструменты. Проверка подключения сама не выдаёт разрешение на все действия.

Поддерживаются текстовые результаты и Bearer-токены. OAuth и локальный транспорт stdio пока не реализованы. MCP доступен моделям, подключённым через API, включая совместимый локальный сервер; модель должна поддерживать вызовы инструментов. Разрешения можно снять, а подключение удалить.

Проверки этой версии

Проверяются одноразовость и срок кода, отзыв, остановка, отсутствие повторной доставки команды, перевод координат снимка, а также HTTP-подключение тестового клиента и скачивание архивов. Автотесты используют искусственный снимок и не управляют настоящим рабочим столом. Реальное управление конкретной моделью требует проверки на своей ОС с выданными разрешениями. Подписанных нативных установщиков в этом локальном выпуске нет.
