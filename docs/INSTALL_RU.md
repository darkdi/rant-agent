# Rant Agent — установка с нуля

Это локальное приложение для одного пользователя. Регистрация в Rant и подписка не нужны. За сторонние API ты платишь своему провайдеру; локальные модели используют ресурсы компьютера.

## 1. Подготовь компьютер

- **macOS или Linux.** Нативная Windows в этой альфе не поддерживается. WSL пока не проверен.
- **Python 3.12 или новее**, с модулем `venv`.
- **Node.js 22.13 или новее**, включая npm.
- **Git** для скачивания и обновлений.
- Обычный браузер для интерфейса. Для браузерного агента нужен **Chrome 120+**.

Для API-режима не нужно скачивать модель. Объём памяти для локальной генерации зависит от модели, контекста и других приложений. Для Qwen 9B разумно начинать с Mac с 16 ГБ памяти, лучше иметь запас; это ориентир, не гарантия работы любого контекста. При нехватке памяти используй меньшую модель в Ollama. Видео требует существенно больше ресурсов, чем чат.

### macOS

Установи Python с [python.org](https://www.python.org/downloads/) и Node.js с [nodejs.org](https://nodejs.org/en/download). Git доступен через инструменты разработчика Apple или [git-scm.com](https://git-scm.com/downloads).

Если Homebrew уже установлен, можно выполнить:

```bash
brew install python@3.12 node git
```

Проверь версии в новом окне Терминала:

```bash
python3 --version
node --version
npm --version
git --version
```

Если `python3` всё ещё старый, используй нужный интерпретатор явно: `PYTHON_BIN=python3.12 ./start.sh`.

### Linux

Установи Git, Python 3.12+ и пакет venv через менеджер пакетов своего дистрибутива. Например, **Ubuntu 24.04**:

```bash
sudo apt update
sudo apt install git python3 python3-venv python3-pip
```

Node.js установи по [официальной инструкции](https://nodejs.org/en/download), затем проверь `node --version`. Не все дистрибутивы поставляют нужную версию Node/Python по умолчанию. Реальный локальный запуск этого выпуска проверен на macOS Apple Silicon; Linux проверяется дополнительно в CI и не означает проверку каждого дистрибутива/драйвера GPU.

## 2. Скачай приложение

```bash
git clone https://github.com/darkdi/rant-agent.git
cd rant-agent
./start.sh
```

Первый запуск создаёт изолированное окружение `.venv`, устанавливает зависимости и собирает интерфейс. Нужен интернет; веса моделей не скачиваются. После сборки откроется **http://127.0.0.1:4311**.

Оставь Терминал открытым. Для остановки нажми **Ctrl+C**. При следующем запуске выполни `./start.sh` из той же папки. На Mac можно открыть `Start-Rant.command`.

Если скачал ZIP через GitHub, распакуй его, открой Терминал в полученной папке и выполни:

```bash
chmod +x start.sh Start-Rant.command
./start.sh
```

`./start.sh --check` только проверяет предпосылки и порты, ничего не устанавливает. `--no-open` отключает автоматическое открытие браузера. `--no-browser` запускает без моста расширения.

## 3. Выбери один способ подключения модели

**Ollama не обязательна.** Достаточно одного варианта: Ollama, LM Studio, встроенная Qwen или API. Подключения чата и генерации картинок/видео отдельные.

### Вариант A. Ollama — локальные модели

1. Скачай и установи [Ollama](https://ollama.com/download), запусти приложение.
2. Скачай модель в Терминале:

```bash
ollama pull qwen3:4b
ollama list
```

3. Проверь ответ без Rant:

```bash
ollama run qwen3:4b
```

Напиши короткий вопрос. Для выхода из чата введи `/bye`.
4. Если служба не запущена, выполни `ollama serve` в отдельном окне. Если пишет, что порт занят, Ollama, вероятно, уже работает; вторую службу запускать не нужно.
5. В Rant нажми название модели сверху → **Добавить модель** → **Ollama**.
6. Адрес: `http://127.0.0.1:11434/v1`. Обычная локальная Ollama не требует API-ключ.
7. Нажми **Получить список с сервера**, выбери точное название установленной модели.
8. Нажми **Сохранить и проверить**, затем **Готово**, отправь сообщение.

Пресет использует формат **Chat Completions**. Он совместим с [Ollama OpenAI API](https://docs.ollama.com/api/openai-compatibility). Rant не устанавливает Ollama и её модели вместо тебя.

Для агентных задач модель должна поддерживать вызов инструментов. Успешный короткий ответ не доказывает, что она справится с браузером или редактированием файлов. Для простого чата сначала оставь автоматическое сжатие выключенным — так меньше дополнительных запросов.

Размер контекста на стороне Ollama настраивается отдельно. Поле контекста в Rant не меняет настройки движка. Например, файл `Modelfile`:

```text
FROM qwen3:4b
PARAMETER num_ctx 8192
```

```bash
ollama create rant-qwen -f Modelfile
```

Затем выбери `rant-qwen` в Rant. Больший контекст расходует больше памяти. [Официальная документация](https://docs.ollama.com/api/openai-compatibility).

### Вариант B. LM Studio

1. Установи [LM Studio](https://lmstudio.ai/), скачай подходящую модель внутри приложения.
2. Загрузи модель. Открой **Developer** и запусти локальный сервер (**Start Server**).
3. В Rant: название модели → **Добавить модель** → **LM Studio**.
4. Оставь `http://127.0.0.1:1234/v1`, если в LM Studio не указан другой порт.
5. Получи список моделей, выбери нужную и сохрани. Ключ не нужен, если ты отдельно не включил авторизацию сервера.

[Инструкция локального сервера LM Studio](https://lmstudio.ai/docs/developer/core/server).

### Вариант C. Встроенная Qwen 3.5 9B через MLX

Только **Mac с Apple Silicon**. Ollama и LM Studio для этого варианта не нужны.

Из корня Rant, после первого запуска:

```bash
.venv/bin/pip install -r requirements-mlx.txt
```

Если весов ещё нет, явно запусти скачивание нескольких гигабайт:

```bash
.venv/bin/python scripts/setup_model.py --download
```

По умолчанию файлы окажутся в `~/Models/Qwen3.5-9B-4bit`. Используется `mlx-community/Qwen3.5-9B-4bit`. Проверь [карточку и лицензию модели](https://huggingface.co/mlx-community/Qwen3.5-9B-4bit) перед использованием.

Если правильные **MLX-веса** уже скачаны, повторно скачивать их не нужно:

```bash
.venv/bin/python scripts/setup_model.py --path "$HOME/Models/Qwen3.5-9B-4bit"
```

Чтобы заменить существующую настройку, добавь `--replace`. Это меняет только путь модели, не удаляет старые веса.

Альтернатива — вручную создать `local-assistant/model-9b.json`:

```json
{"path": "/полный/путь/к/Qwen3.5-9B-4bit"}
```

Нужна папка модели с `config.json`, файлами токенизатора и всеми `.safetensors`. GGUF из Ollama/LM Studio не подходит этому MLX-загрузчику.

Перезапусти Rant, выбери **Qwen3.5-9B · MLX 4-bit** и напиши сообщение. Первый запрос загружает модель; затем статус станет **Qwen в памяти**. В настройках есть **Выгрузить Qwen из памяти**. Встроенный режим в этом выпуске работает с текстом; картинки передавай модели с поддержкой зрения через подходящий API.

[MLX-LM](https://github.com/ml-explore/mlx-lm) — отдельный движок с собственной документацией. Rant не обучает модель и не включает веса в репозиторий.

### Вариант D. API со своим ключом

1. Получи ключ у выбранного провайдера. Подписка на чат-сайт и доступ к API могут оплачиваться отдельно.
2. В Rant открой **Добавить модель** и выбери провайдера или **Другой сервис**.
3. Укажи базовый адрес API, например адрес до `/v1`, а не полный путь `/chat/completions`.
4. Вставь ключ, получи список моделей или введи точный ID из кабинета провайдера.
5. Проверь формат в дополнительных настройках: **Chat Completions**, **Responses** или **Anthropic Messages**. Не все провайдеры поддерживают все три.
6. **Сохранить и проверить** отправляет реальный короткий запрос — он может тарифицироваться. **Сохранить** только записывает подключение.

Ключ хранится локально, переживает перезапуск и не отображается обратно в поле. Удалить сохранённый ключ можно в настройках подключения. Изменение адреса на другой сервер не переносит прежний ключ автоматически.

## 4. Подключи Chrome

Расширение не требуется для обычного чата. Safari может показывать интерфейс Rant, но агент управляет **Chrome**.

1. Запусти Rant. При старте он создаст персональный `sever-ide/chrome-extension/config.js`.
2. В Chrome открой `chrome://extensions` и включи режим разработчика.
3. Нажми **Загрузить распакованное расширение** и выбери **`sever-ide/chrome-extension` именно этой копии Rant**.
4. Закрепи расширение **Rant Agent Local — браузер**, открой его и нажми **Разрешить Chrome**. Chrome покажет запрашиваемые разрешения.
5. В Rant открой **Настройки и возможности → Доступы**, включи браузер и сохрани разрешения. Под полем сообщения выбери режим браузера.
6. Начни с чтения обычной публичной HTTPS-страницы. Вход на сайты, пароли и коды вводи сам в Chrome.

Мост выбирает свободные порты и сохраняет их в `.local/browser-ports.json`. Разные копии Rant имеют разные токены и настройки. Не заменяй расширение, используемое другим приложением: для этой копии загружай её собственную папку. После обновления кода нажми ↻ на её карточке в `chrome://extensions`.

Не публикуй `config.js`, токен расширения или всю `.local`. Ошибка «мост запущен, Chrome не подключён» обычно означает, что расширение ещё не загружено, не обновлено или относится к другой папке.

## 5. Проекты и файлы

Нажми **+** рядом с проектами и создай пространство. Новые папки создаются в `sever-ide/projects`; личные чаты могут иметь внутренние папки в `.local/workspaces`. Включи **Файлы и код**, чтобы открыть редактор, историю изменений и предпросмотр.

Приложение умеет ограниченные правки текстовых файлов. Это не терминал: оно не запускает произвольные команды, тесты твоего проекта или деплой. Предпросмотр предназначен для статических HTML/CSS/JS. Ограничения текущего файлового инструмента: до 24 КБ на файл и 100 индексируемых файлов.

## 6. Изображения и видео

На стартовом экране нажми **Создать картинку** или **Создать видео**. Эти кнопки доступны также в боковом меню. Сначала добавь отдельное медиа-подключение. [Полная инструкция студии](MEDIA.md).

## 7. Обновления и резервная копия

Останови Rant через Ctrl+C. Сохрани копию `sever-ide/.local`, `sever-ide/projects`, `local-assistant/model-9b.json` и своих внешних проектов в личное защищённое место. Архив содержит ключи и личные данные — не прикладывай его к GitHub issues.

```bash
git pull --ff-only
./start.sh
```

Если менял исходники, сначала сохрани свои изменения. `--ff-only` не перепишет их и остановится при конфликте. Лаунчер заметит изменения зависимостей и интерфейса; для принудительной пересборки используй `./start.sh --rebuild`.

## 8. Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `command not found` | Python/Node/Git установлены и доступны в новом Терминале |
| Нельзя создать `.venv` | На Linux установлен пакет `python3-venv`; текущая папка доступна для записи |
| Порт 4311/4312 занят | `./start.sh --port 4321 --preview-port 4322`; открой адрес, напечатанный в Терминале |
| `Permission denied` у start.sh | `chmod +x start.sh Start-Rant.command` |
| Qwen требует настройки | Установи requirements-mlx.txt в **то же** `.venv`, проверь путь и формат весов |
| Модель очень медленная / завершается | Закрой тяжёлые приложения, сократи контекст или выбери меньшую модель; ошибки загрузки видны в настройках |
| Ollama/LM Studio не отвечает | Проверь сервер вне Rant, порт и список установленных моделей |
| HTTP 401/403 | Ключ или права доступа провайдера; локальный сервер может иметь собственную авторизацию |
| HTTP 404 | Неверный базовый адрес, формат API или точное имя модели |
| Браузер не подключён | Проверь путь расширения, ↻, разрешения и то, что Chrome открыт |
| Медиа требует проверки | Проверь ID в сервисе; запрос не повторялся автоматически. Провайдер мог принять и оплатить его до разрыва связи |
| Старые цвета/логотип | Обнови вкладку Cmd+R / Ctrl+R после сборки |

В bug report укажи ОС, версии Python/Node, выбранный движок, шаги и текст ошибки. Удали ключи, личные пути и содержимое переписок. Это ранняя альфа: не все модели, сайты и системы проверены.
